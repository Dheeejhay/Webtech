CSS Selectors Laboratory

Element selectors style all matching HTML tags across a page.

Class selectors style multiple elements that share a common class name.

ID selectors target a single unique element and have higher specificity than a classes or elements.

Element Selectors

Type selectors match tag names directl, such as body, h1, or p.

Class Selectors

Class selectors start with a dot (.) and can be applied to many elements.

ID Selectors

ID selectors start with a hash (#) and are meant for unique elements like #page-title.
