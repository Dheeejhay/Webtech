Text Formatting Tags

Bold Makes text bold.

Strong This indicates that the text is important.

i This displays the text in italic style.

em This emphasizes text.

u This underlines text.

mark This highlights text.

small This displays smaller text.

del This indicates deleted text.

ins This indicates inserted text.

sub This used to define subscription text.

sup This is used to define superscript text.
